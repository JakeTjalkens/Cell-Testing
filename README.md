This repository contains data analysis / visualization scripts for various electrochemical 
characterization techniques that accept data files from tests ran on Arbin cyclers. Data files from other
cyclers will also work, but naming conventions will need to be tweaked inside the script.

Under diffusion, complete analysis scripts for the following tests can be found:
Galvanostatic Intermittent Titration Technique (GITT)
Intermittent Current Interruption (ICI)

Under impedance, a circuit fit / NyQuist plotting script can be found.
